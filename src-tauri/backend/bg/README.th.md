# Background art (rotating)

Folder นี้คือหลังบ้านเขาของหน้าแอป: launcher จะหมุนวนทุกภาพในโฟลเดอร์นี้ (เฟดตัดกัน
ทุก 12 วิ) — โยนไฟล์ JPG / PNG / WebP ใส่ได้เลย เดี๋ยวระบบเปิดรายการเจอเองที่
`/bg/<ชื่อไฟล์>` ไม่ต้อง rebuild

ชุดปัจจุบัน: `bg1.jpg` … `bg5.jpg` (ภาพของผู้ใช้, หมุนวนตามชุดนี้)

`Logo.png` ในโฟลเดอร์นี้คือ **asset โลโก้ sidebar** ไม่ใช่ภาพพื้นหลัง —
endpoint `/api/bg/list` ตั้งใจข้ามไฟล์ที่ขึ้นต้นด้วย "logo" ไว้แบบนั้น
